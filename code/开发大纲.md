# YOLOv8 蜜蜂瓦螨图像二分类 · 开发大纲

## 研究目标

暂定题目为《基于 YOLOv8 的蜜蜂瓦螨寄生图像二分类研究》。输入单只蜜蜂的照片，输出“有可见瓦螨”或“无可见瓦螨”。数据来自受控拍摄环境，论文结论以该数据上的单图分类表现为限。

主实验检验等比例缩放后补边能否比默认裁剪减少有螨图像的漏判。可视化平台用于启动实验、记录参数、比较结果和演示。

## 数据准备

原开发机可直接使用 `D:\azst\myCode\DataSet\VarroaDataset-cls`。换机器可拷贝并解压约 1.08 GiB 的 `VarroaDataset-cls.zip`，或从 Zenodo 下载三个原始 ZIP 后按下述规则复现。配置时指向包含 `train/`、`val/`、`test/` 的那一级目录。计划由 Compose 配置宿主机路径并将数据只读挂载，不把数据复制进镜像。[VarroaDataset 1.2.0 官方下载](https://zenodo.org/records/4085044)

| 官方划分 | `no_mite` | `mite` | 合计 |
|---|---:|---:|---:|
| `train` | 5,670 | 2,553 | 8,223 |
| `val` | 1,425 | 451 | 1,876 |
| `test` | 2,466 | 942 | 3,408 |
| **总计** | **9,561** | **3,946** | **13,507** |

整理规则如下。

1. 沿用作者的划分。读取各 ZIP 内的 `gt_one.csv`，每行前两项分别是图片路径和原始标签。Zenodo 单独提供的 `gt.csv` 与三份分表逐条核对一致。
2. 原始标签 `0` 对应 `no_mite`，`1` 和 `3` 合并为 `mite`。原始标注中 `1` 有 3,083 条，`3` 有 864 条，合计 3,947 条，与作者公布的阳性数一致。所有 `3` 记录都有位置框。作者未公开解释 `3` 与 `1` 的具体区别，论文应写清这是本实验的二分类映射。
3. 按标签复制原始 PNG 至相应类别目录。训练集两张图各有一条重复记录，各保留一份。已校验复制前后文件内容一致，三个划分之间未发现内容完全相同的图片。原始 TXT 的位置框可供复核，分类模型从类别目录读取标签。

## 实验设计

- **模型与对照。** 两组都从相同的 `YOLOv8n-cls` 预训练权重开始。A 组采用 Ultralytics 分类默认裁剪，B 组等比例缩放后补边。固定数据划分、输入尺寸、轮数、批大小、随机种子及其他训练设置。验证阶段使用各自匹配的预处理，并记录库版本和实际参数。
- **评价方法。** 训练过程展示每轮训练损失、验证损失和验证准确率。对比实验重点报告有螨类召回率、宏平均 F1 和混淆矩阵。按模型的类别名称查找 `mite` 的索引，计算有螨样本被判成无螨的数量和比例。
- **测试集使用。** 在验证集对比和选定方案后，再用 `test` 评估所选权重。保存参数、每轮指标、验证与测试结果及权重，方便论文复现。
